# Feldzuordnung für Anlage 6 der ZVFV, Forderungsaufstellung zum Vollstreckungsauftrag an
# Gerichtsvollzieher.
#
# Spalten: Feldname <TAB> Schluessel <TAB> Pflicht (0/1) <TAB> Bezeichnung
#
# Das Formular ist kein Formular mit Zeilen, sondern eines mit Plaetzen: zwei Bloecke fuer
# titulierte Hauptforderungen, drei fuer titulierte Kosten, je Block zwei Zinszeilen mit Endedatum
# und zwei ohne, und je Abschnitt eine freie Zeile. Welche Forderung wohin gehoert, entscheidet
# EnforcementItemisationSlots - das ist eine rechtliche Aussage und keine Formatierung: was unter
# "Festgesetzte Kosten" steht, behauptet einen Kostenfestsetzungsbeschluss.
#
# Die Feldnamen sind wieder nichtssagend, und die Tooltips diesmal auch - "Betrag", "Zahl",
# "Datum von". Was ein Feld bedeutet, ergibt sich erst aus seinem Platz auf dem Blatt. Die
# Zuordnung ist deshalb nicht aus der Reihenfolge geraten, sondern aus der Geometrie gelesen: die
# Rechtecke der Felder aus dem PDF, die gedruckten Beschriftungen mit ihren Koordinaten daneben,
# und dann Zeile fuer Zeile abgeglichen.
#
# Nicht zugeordnet und deshalb leer:
#  - Abschnitt II (rueckstaendiger Unterhalt): der gehoert in die Anlage 8.
#  - Der dritte Hauptforderungsblock: er traegt die Saeumniszuschlaege, ein steuerrechtlicher
#    Zuschlag, den das Forderungskonto nicht fuehrt.
#  - Die zweite ausgerechnete und die zweite laufende Zinszeile je Block: eine Forderung des
#    Kontos hat einen Zinslauf, nicht zwei.
#  - Abschnitt IV, "Bisherige Vollstreckungskosten gemaess Aufstellung in weiterer Anlage": die
#    Zeile verweist auf eine Anlage, die wir nicht beilegen. Frueher gebuchte Vollstreckungskosten
#    stehen stattdessen in der freien Zeile desselben Abschnitts - einmal, nicht zweimal.
#  - Die Kosten des Gerichtsvollziehers: sie haengen an seinen Amtshandlungen, nicht am Wert, und
#    stehen im Vorschlag ohne Betrag (Aufgabe 0.3).
#  - "Lfd. Nr." und "zu Ziffer": beides nummeriert der Auftrag, dem die Anlage beiliegt.
#
# Pflicht ist allein die Summe. Ein Auftrag kann aus lauter Kosten bestehen und ohne
# Hauptforderung auskommen; die Summe kann er nicht.
